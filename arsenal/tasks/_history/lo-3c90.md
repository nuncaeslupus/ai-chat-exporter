## Acceptance gate

**Gate**: `getTitle()` returns the real conversation title and `getModel()` the
real model label, both verified against a **freshly captured** Gemini DOM — not
against the January fixture, which still contains the old markup.

```bash
pnpm typecheck && pnpm test:run
```

## What the code assumes

`src/core/parsers/gemini/selectors.ts`:

- `conversationTitle: '.conversation-title-container .conversation-title'`
- `modelIndicator: '[data-test-id="bard-mode-switcher"] [data-test-id="bard-text"]'`

## What the live page does

Both match **zero** elements on a current Gemini page (found while implementing
Deep Research, `lo-1316` / PR #55):

- The top bar no longer carries the conversation title at all.
- `bard-mode-switcher` moved into the composer and now reads a tier label
  ("Pro" / "Extended") rather than a model name.

`getTitle()` therefore always falls back to `'Gemini Conversation'` and
`getModel()` always returns `null` — silently. Every Gemini export is filed
under a generic title with no model recorded.

## Why the tests do not catch it

The committed fixture `tests/fixtures/dom-snapshots/gemini/real-capture.html`
is a January capture that **still contains both elements**, so the
selector-liveness guard passes. This is the fixture-staleness failure mode in
its purest form: the guard proves the selector matches *the fixture*, not the
product. Documented in `docs/dev/parser-gotchas.md` §12d.

## Work

1. Load the **parser-generator** skill and follow its live-capture workflow.
   Capture a current Gemini page into `tmp/examples/` (gitignored) — do not
   reason from this payload's description of the DOM.
2. Find where the title and the model actually live now. Check `document.title`
   as a title source; Gemini may only expose the conversation name in the
   sidebar (as ChatGPT does), in which case decide deliberately whether to read
   it there or accept the fallback and say so in a comment.
3. Update the selectors, and refresh the committed fixture so the liveness guard
   is testing current markup. Sanitize it — invented content only.
4. If a selector genuinely has no live equivalent, move it to the documented
   no-coverage list with a reason rather than leaving a dead selector that
   silently falls back.

## Tests

- Assert `getTitle()` returns the fixture's real title, not the default.
- Assert `getModel()` returns a non-null label.
- Both RED against the current selectors before the fix.
