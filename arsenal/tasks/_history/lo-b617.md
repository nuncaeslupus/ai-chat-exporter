## Acceptance gate

**Gate**: typing "add a parser for a new chatbot" in a session loads the skill; its instructions produce code that compiles against `base-parser.ts`.


Prose-only gate — verified by worker judgment, no script to run.

## What exists today

`.agents/parser-generator/skill.md` (553 lines) plus `prompts/analyze-chatbot.md` (278) and `prompts/generate-parser.md` (709). Substantial, thoughtful content — and completely inert:

- Wrong location. Claude Code loads skills from `.claude/skills/`, not `.agents/`.
- No YAML frontmatter (`name`, `description`), so nothing can trigger it.
- References `ADDING_PARSERS.md`, a file that does not exist (it is `docs/dev/adding-parsers.md`).
- Encodes the same wrong API as that guide — `extractMessages`, `platformInfo.platform`, argument-less constructors. See `lo-58b0`.
