## Acceptance gate

**Gate**: exporting from claude.ai no longer serializes the full document.


Prose-only gate — verified by worker judgment, no script to run.

`src/core/services/claude-api-service.ts:64-81` (`extractOrganizationId`) calls `document.documentElement.innerHTML` — serializing the **entire page**, not the conversation container — then runs three regexes over the result and logs a 1000-char slice. Reached on every export and every print via `extractIdsFromPage` → `enrichClaudeConversation`. On a long code-heavy conversation that string is multiple MB, built synchronously on the main thread, per click, with no caching across the export and print calls in one session.

Fix direction: scope the query to the element that actually carries the org id, or read it from a cookie/`__NEXT_DATA__`-style source. Cache the result for the page lifetime.
