## Acceptance gate

**Gate**: a multi-line code block in a DOCX export opens in Word with its line breaks intact.


Prose-only gate — verified by worker judgment, no script to run.

`src/core/exporters/docx-exporter.ts:414` — `renderCodeBlock()` puts the code string into a docx `TextRun` without converting `\n` into docx line breaks. In OOXML a literal newline inside a run is not a break; Word collapses it. A 40-line function exports as one unreadable line.

Fix: split on `\n` and emit a `TextRun` per line with `break: 1`, or use one paragraph per line with the code style applied.

Test: `it('preserves line breaks in DOCX code blocks')` — assert the produced document contains as many break elements as the source has newlines.
