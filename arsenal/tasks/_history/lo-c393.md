## Acceptance gate

**Gate**: `tests/integration/` contains a suite that parses a real fixture and runs the result through all six exporters.


Prose-only gate — verified by worker judgment, no script to run.

`tests/integration/` exists and is empty. Parser tests and exporter tests are fully isolated: exporters are fed hand-built `Conversation` objects from `tests/utils/exporter-helpers.ts`, never the output of a real parser. A shape mismatch between what parsers actually emit and what exporters expect would pass both suites and break in production.

## Tests

- `it('parses the ChatGPT capture and exports it to every format without throwing')`
- per format: assert expected substrings survive the round trip (a code block, a heading, a link)
- assert artifact and web-search metadata reaches the export — the parser suite proves it is extracted, and nothing currently proves it is rendered
