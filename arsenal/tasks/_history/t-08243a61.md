### Finding
The Markdown print path runs marked's output through sanitizeHtml, whose attribute allowlist has no 'start', 'colspan', 'rowspan' or 'align', and which deletes non-allowlisted elements together with their text. An answer whose list resumes at '3.' after a code block prints as '1.', GFM task lists lose their checkboxes, and inline HTML such as <details>/<mark>/<kbd>/<s> in the Markdown vanishes with its content. The same sanitiser gates the ChatGPT deep-research HTML tier, where up to 50% text loss is tolerated before falling back.

### Evidence
traced code path (node_modules absent, tests could not be run): marked emits <ol start="3"> and <input type=checkbox>; ALLOWED_ATTRS has entries for a/img/svg/pre only; disallowed nodes go to toRemove and el.remove() takes the subtree.

### Suggested direction
Unwrap unknown elements (keep children) instead of removing them, and allow inert structural attributes (ol[start], td/th[colspan,rowspan,align]).
