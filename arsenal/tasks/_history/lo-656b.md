**Spec: `docs/design/popup-redesign.md` § "3. Submenú Contenido → Elegir pares"**.

## Acceptance gate

**Gate**: every Q&A pair is listed with a checkbox, clamped to two lines with a
working `más`/`menos` expander, grouped by day separators, and the footer counts
both selected pairs and words — all inside the same 260 px body, scrolling
internally.

```bash
pnpm lint && pnpm typecheck && pnpm test:run && pnpm build
```

## Work

- Three bands: submenu header (`flex:none`), list (`flex:1; overflow-y:auto`),
  footer (`flex:none`).
- Rows: 15 px checkbox, pair number in **normal** type with `tabular-nums`
  (explicitly not monospace), question clamped to 2 lines
  (`-webkit-line-clamp:2`, never mid-word) plus a `más` link; expanded rows show
  the full text, tint `#F7FAF8`, and the link becomes `menos`.
- **Day separator** when a pair's date differs from the previous one.
- Selection goes through `SelectionService` — `toggleSelection`, `selectAll`,
  `deselectAll`. `más`/`menos` only expands; it must never change selection.
  (`lo-8f9b` just fixed the test that failed to prove `toggleSelection` does not
  mutate its input — do not reintroduce mutation.)
- Footer: `2 de 14 · 4.120 palabras`, `tabular-nums`, and a `Hecho` button.
  Number formatting must follow the active locale, not a hardcoded separator.

## Tests

jsdom: expanding a row does not alter selection; `Todos`/`Ninguno` set every
checkbox and the footer count; a day separator appears exactly at each date
change and never before the first row; the word count matches the selected pairs
only.
