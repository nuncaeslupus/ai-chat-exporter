## Acceptance gate

Prose-only gate — verified by worker judgment, no script to run.

1. `manifests/manifest.firefox.json:2` hardcodes `"name": "AI Chat Exporter and Printer"`, overriding the base `__MSG_extensionName__`. Confirmed in the built `dist/firefox/manifest.json`. The extension is already live on AMO — check what id the published version actually carries before changing anything here. If the placeholder is what shipped, it stays; document that it is deliberate.
