**Spec: `docs/design/popup-redesign.md` notes 5 and 6.** This is the
exporter-side half of the redesign — it touches no popup file and can run in
parallel with the R-tasks.

## Acceptance gate

**Gate**: with the chat-header option on, every format's header carries
platform, model, **conversation date range**, export date and URL; with
timestamps on, each format emits a day separator at a date change instead of a
date on every message.

```bash
pnpm lint && pnpm typecheck && pnpm test:run && pnpm build
```

## Work

1. **Header** — the date range of the conversation is new; platform, model,
   export date and URL already exist in some formats. Check all six: this is the
   same class of gap `lo-5970` and `lo-23fb` cover, where a field reaches some
   exporters and not others.
2. **Day separator** — `— 29 jul 2026 —` at each day change when timestamps are
   on; the per-message date goes away, the per-message **time** stays. Date
   formatting follows the export locale.

Both changes are per-format rendering, so follow whatever block pattern
`conversation-structure-service.ts` already uses (see how `MediaBlock` was added
in PR #99) rather than special-casing inside each exporter.

## Tests

One test per format for each half: header contains all five fields; a two-day
conversation emits exactly one separator, at the boundary, and none for a
single-day conversation.

## Location

`src/core/exporters/*`, `src/core/services/conversation-structure-service.ts`,
`src/core/types/structured-content.ts`.
