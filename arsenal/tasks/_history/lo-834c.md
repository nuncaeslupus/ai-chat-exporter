Spec Phase 2 / DOCX. Depends on R-1.

- Declare `ChatTitle`, `ChatBody`, `ChatRole`, `ChatCode` with all formatting
  explicit, replacing Word's built-in `Heading N`. This is what makes the file
  render identically in anyone's Word instead of inheriting their stylesheet.
- Calibri + Consolas (present in every Office install, Windows and Mac).
- **DOCX sets no page size today** — it silently takes the `docx` library
  default regardless of the user's preference. That is the real paper-size bug.
  Add explicit `SectionProperties` page size for a4 | letter | legal, same
  margins in mm as the PDF.
- Tables: explicit borders, 100% width, `cantSplit` on rows, header row
  repeated across page breaks.
- `keepNext` on labels and headings, `keepLines` on short paragraphs.
- Page number as a real Word field, bottom right — not literal text.
