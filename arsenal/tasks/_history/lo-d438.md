## Acceptance gate

**Gate**: every `data-i18n` key used by the popup exists in **all seven**
locales, no locale has keys the popup no longer uses, and the check runs in the
test suite so it cannot rot.

```bash
pnpm lint && pnpm typecheck && pnpm test:run
```

## Work

The redesign adds keys across R2–R7, each PR touching all seven
`_locales/*/messages.json`. This task is the closing check, not the bulk
translation: run it last, fix what drifted, then **write the test that keeps it
true** — parse `popup.html` for `data-i18n` attributes and every
`getMessage('…')` call in `popup.ts`, and assert the key set matches each
locale's key set exactly.

Locales: `ca`, `de`, `en`, `es`, `fr`, `it`, `pt`.

A missing key in a locale is silent at runtime — the label just renders empty —
which is why this is a test and not a review step.

## Tests

The audit test itself. Prove it works by deleting one key from one locale and
confirming it fails.

## Location

`_locales/*/messages.json`, `tests/unit/extension/popup/`.
