**Spec: `docs/design/popup-redesign.md` § "4. Submenú Opciones"**.

## Acceptance gate

**Gate**: three rows — chat-header, per-message time, filename — persist through
`StorageService`, and the green dot next to `Opciones` on the main view appears
if and only if some preference differs from its default.

```bash
pnpm lint && pnpm typecheck && pnpm test:run && pnpm build
```

## Work

- `Cabecera con los datos del chat` and `Hora en cada mensaje` as checkboxes
  bound to `includeMetadata` / `includeTimestamps` in `StorageService`.
- **The date-on-day-change is not an option**: when timestamps are on, the day
  separator is always emitted (that exporter half is `lo-3900`).
- `Nombre del archivo` is a navigation row showing the real resulting filename
  underneath in monospace with ellipsis; it opens the R6 view.
- Footer: version, `Privacidad` and `GitHub` links, `Hecho`.
- The changed-from-default dot is derived by comparing against the defaults
  object, not by a second stored flag.

No explanatory paragraphs in this view — the spec is explicit that it stays bare.

## Tests

jsdom: toggling a checkbox writes through `StorageService` and survives a
re-open; the dot is absent at defaults, present after any single change, and
absent again once reverted.
