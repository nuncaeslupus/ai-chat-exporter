# P-4: settings gear for theme and About

Author feedback, 2026-07-30: "Should we have a gear for settings? It could show
the theme (light/dark/auto) and the about info, instead of it being in Options."

**Two parts, and the first is a real feature, not a move.**

1. **Theme preference does not exist yet.** Dark mode is driven purely by
   `@media (prefers-color-scheme: dark)` in both `popup.css` and the exported
   HTML. A light/dark/**auto** choice needs a stored preference, a `data-theme`
   attribute on the root that overrides the media query, and a decision on
   whether it also applies to the exported HTML (it should — the export carries
   its own dark block).
2. **About** — version, Privacy and GitHub links currently live in the Options
   submenu footer. Moving them to a gear frees that footer.

**Open question for the author:** whether the gear replaces the Options row or
sits beside it in the header. Options would still hold Show meta-info, Text size
and File name, so it does not disappear.

**Note:** the popup's design invariant is a fixed 420x(56+320) box. A new
top-level surface must fit that same box, like every other submenu.

## Acceptance gate
