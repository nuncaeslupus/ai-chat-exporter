# P-3: integrated scrollbar for the format menu

Author feedback, 2026-07-30: "About vertical scroll bar when deciding the export
format type, could we use an integrated-style bar?"

The format menu (`.format-menu__list`) is `overflow-y: auto` with the OS default
scrollbar, which on Windows and Linux is a wide grey gutter that breaks the
menu's rounded, floating look.

**Current:** `.format-menu__list { overflow-y: auto; padding: 0 7px 7px; }`

**Fix direction:** slim, self-coloured scrollbar via `scrollbar-width: thin` +
`scrollbar-color` (Firefox, and Chrome 121+) with `::-webkit-scrollbar` for
older Chrome. Use the existing surface/muted tokens so it works in both themes —
do not hardcode greys, the popup has a full dark palette.

**Apply to every scrolling area in the popup**, not just the format menu: the
pair chooser and the options list scroll too, and a menu that looks different
from the list beside it is worse than the default.

## Acceptance gate

Scroll areas show the slim bar in both colour schemes and no scroll area keeps
the default.

```bash
pnpm test:run tests/unit/accessibility/contrast.test.ts
```

## Tests
Contrast test guards the palette. The scrollbar colours must come from tokens,
so a hardcoded grey that fails dark mode is caught.
