# P-1: popup needs more horizontal breathing room

Author feedback, 2026-07-30: "the popup could have some more internal left and
right padding (do it slightly bigger if you need it)".

**Current values** (`src/extension/popup/popup.css`):

- `--popup-width: 420px`
- header `.popup-header` padding `14px 18px`
- `.setting-rows` padding `14px 18px 0`
- `.conversation-block` / body areas padding `16px 18px 0`

So the horizontal inset is **18px** throughout. The ask is more.

**Explicitly allowed:** grow `--popup-width`. Chrome's ceiling is 800px and the
popup is 420px, so there is plenty of room. Widening is preferable to squeezing
the content column.

**Do it once, at the token.** The 18px appears in several rules; introduce a
`--pad-x` custom property and use it everywhere rather than editing each rule,
or the next change repeats this hunt.

**Watch:** the fixed body height (`--body-height`) and the "popup never changes
size" invariant from the design. Widening is fine; the box must still not jump
between states.

## Acceptance gate

The popup renders at the new width with no horizontal scrollbar and no state
that changes height.

```bash
pnpm test:run tests/unit/extension/popup/
```
