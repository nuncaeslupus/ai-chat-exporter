# R-5: plain text — 72 columns, three underline levels, ASCII tables

Spec Phase 2 / plain text. Depends on R-1.

- Fixed 72-column width; the separator rule spans all 72.
- Three underline levels: `=` title, `-` role label, `~` body heading. Each
  underline is the exact width of the text above it.
- Role label uppercase with the time.
- Question indented two spaces — the plain-text equivalent of the PDF's fill.
- Tables: ASCII box when there is a header row (`=` under the header);
  key/value pairs aligned only, no box.
- Code: **fenced with the language, not indented.** Decided deliberately —
  indenting four spaces steals columns and wraps long code lines at 72.
