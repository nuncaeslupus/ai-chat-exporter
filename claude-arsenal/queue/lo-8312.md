# Payload: lo-8312 — Exported HTML leaks visited domains to Google

## Acceptance gate

**Gate**: an exported HTML file makes no third-party network requests when opened offline.


Prose-only gate — verified by worker judgment, no script to run.

`src/core/parsers/chatgpt/parser.ts:679` builds favicon URLs as `https://www.google.com/s2/favicons?domain=${domain}&sz=32` for every web citation. Those URLs are written into the exported document, so **every time anyone opens the export**, Google receives a request revealing the domains cited in that conversation — and the referring context. The user exported the file to keep it locally; the file phones out.

This also directly contradicts the "No External Servers" listing claim (`lo-72f1`).

Fix: inline the favicon as a data URI at export time, or drop favicons. Inlining still fetches once during export — decide whether that is acceptable and disclose it, or make it opt-in.
