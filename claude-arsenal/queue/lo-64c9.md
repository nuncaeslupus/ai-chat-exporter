**1 findings** in this task: 1 critical.

## Findings

### [critical] PDF silently deletes all CJK / Arabic / Hebrew / Cyrillic text — no glyph, no placeholder, no warning

- **Where:** `src/core/utils/pdf-characters.ts`:234
- **Problem:** The embedded faces are Latin-only: `EMBEDDED_FONT_COVERAGE` (pdf-fonts.generated.ts:57-83) is [32-126], [160-255] plus ~20 punctuation singletons. `sanitizeTextForPDF` only rewrites codepoints that appear in `PDF_CHARACTER_REPLACEMENTS` and strips emoji; any other uncovered codepoint is passed through verbatim to jsPDF, which drops it from the content stream entirely because the subset font has no cmap entry. The export reports success and the pages come out blank where the text should be.
- **Failure scenario:** Export a Chinese, Japanese, Korean, Russian, Hebrew or Arabic conversation to PDF → the message bodies are empty. Verified against the real generated fonts: `doc.text('你好')` produces the content-stream operator `<> Tj` (empty glyph string, nothing drawn), and mixed input `a你b` produces `<001c001d> Tj` — 2 glyphs for 3 characters, the CJK char silently deleted. `sanitizeTextForPDF('你好世界')` returns the string unchanged, so nothing upstream catches it. Same for `مرحبا`, `שלום`, `Привет`. No test or doc covers this (`grep -rniE 'cjk|chinese|arabic|hebrew|cyrillic' docs/` → nothing).
- **Suggested fix:** At the end of `sanitizeTextForPDF`, map any remaining codepoint not in `EMBEDDED_FONT_COVERAGE` to a visible placeholder (e.g. U+FFFD or '?') so the loss is visible rather than silent — reuse the existing `embeddedFontRenders()` helper per codepoint. Longer term, either embed a CJK-capable subset or detect uncovered scripts in `PdfExporter.export()` and surface a warning to the popup ('PDF cannot render this script — try DOCX/HTML'). Note also that pdf-exporter.ts:265, 272, 288 and 295 (platform/model/exported/url metadata) bypass `sanitizeTextForPDF` altogether, so those lines are unprotected even for the mapped characters.
- **Evidence:** pdf-fonts.generated.ts:57-83 coverage ranges (Latin + punctuation only); jsPDF content stream for '你好' = `BT /F15 12 Tf ... <> Tj ET`; for 'a你b' = `<001c001d> Tj`; `sanitizeTextForPDF('你好世界') -> '你好世界'` (codepoints 4f60,597d,4e16,754c unchanged).
