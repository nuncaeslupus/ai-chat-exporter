# Payload: lo-5d45 — link destinations are discarded by txt and pdf

**Gate**: a link's URL survives into every text-bearing format, proven by a test
per format.

```bash
pnpm typecheck && pnpm test:run
```

## The defect

`txt-exporter.ts` and `pdf-exporter.ts` flatten inline content with
`content.map(i => i.text).join('')`, which cannot see `InlineContent.url`. A PDF
of a citation-heavy answer keeps every anchor's text and loses every destination —
the reader sees the words with no way to reach the source.

Found by the completeness matrix in `.claude/skills/exporter-generator/references/completeness-matrix.md` (PR #52).

## Work

Decide a rendering per format and apply it consistently:
- txt: `text (url)` is the conventional plain-text form.
- pdf: either a real link annotation or the same `text (url)` fallback.

Check the other four formats render links correctly rather than assuming.

## Tests

- One test per format asserting both anchor text and URL appear.
- RED first against current `main`.
