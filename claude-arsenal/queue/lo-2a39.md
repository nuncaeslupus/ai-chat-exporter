# DOCS-1: documentation truthfulness — README lists four shipped features as missing, store listings omit two permissions

Source: the 13-dimension senior review of 2026-07-31 (26 agents, findings adversarially reviewed).
**26 findings** in this task: 6 high, 14 medium, 6 low.

The store-listing omission matters most: the listing's permission justifications do not mention
`scripting` or the web-sandbox host permission that the manifest actually requests. That is a review
risk, not just a docs nit.

Fix by making the docs match the code, except where the code is the thing that is wrong (the dead
button-injection feature — coordinate with DEAD-1).

### [high] README and usage.md both say four shipped features do not exist (pair selection, options UI, timestamps, filename template)

- **Where:** `README.md`:208
- **Problem:** README.md:208-218 ("Not implemented yet") states: "Selecting which Q&A pairs to export… Every export includes the whole conversation" and "An options UI.
