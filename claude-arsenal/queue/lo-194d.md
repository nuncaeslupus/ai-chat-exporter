# Payload: lo-194d — Gemini host permissions

## Acceptance gate

**Gate**: `make build && grep -c gemini.google.com dist/chrome/manifest.json dist/firefox/manifest.json` returns ≥2 for each.


Prose-only gate — verified by worker judgment, no script to run.

## Work

Add `https://gemini.google.com/*` to `host_permissions` and to the `content_scripts[0].matches` array. Without this the content script never injects on Gemini, so no amount of parser work is observable in a browser.
