# P-2: row chevrons sit too close to the right edge

Author feedback, 2026-07-30: the arrows on the **Contenido** and **Opciones**
rows "are too close to the right border, I'd like more breathing space".

**Why it happens:** `.setting-row` has `padding: 0 2px` inside `.setting-rows`,
which has `padding: 14px 18px 0`. The chevron therefore ends ~20px from the
popup edge while its row's hover tint runs to 18px — the arrow looks pinned to
the frame.

**Fix direction:** give the chevron its own right inset, or increase the row's
horizontal padding, so the arrow has visible margin inside the row's hover
rectangle. Applies to every navigable row (Contenido, Opciones, Nombre del
archivo), not just the two named.

Best done together with **P-1 (`lo-a948`)**, which is retuning the same
horizontal rhythm — doing them separately means measuring the same thing twice.

## Acceptance gate

all of them agree.
