# Payload: lo-08b0 — Concurrent exports race

**Gate**: triggering export twice in quick succession produces one file, or two correct ones — never a corrupted result.

`src/extension/content/content-script.ts:18` — the `ContentScript` instance holds mutable state (`conversation`, `initialized`) and there is no re-entrancy guard. A double-click on Export, or Export while a Print is mid-flight, runs two async pipelines that re-parse and overwrite shared state under each other. Trivial to trigger: the button gives no feedback (`lo-2086`), so an impatient user clicking twice is the *expected* interaction.

Fix: an in-flight flag that disables the trigger and gives feedback, or make the pipeline operate on a local snapshot instead of instance state — the latter fixes the class rather than the instance.
