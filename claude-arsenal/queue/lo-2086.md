# Payload: lo-2086 — Failures are reported as success

## Acceptance gate

**Gate**: a failed export produces a visible error in the popup; a conversation with zero pairs cannot be silently "exported".


Prose-only gate — verified by worker judgment, no script to run.

## Confirmed

- `src/extension/content/content-script.ts:142-143` — `handleExport`'s catch block only calls `console.error`. The error never propagates.
- `content-script.ts:598-601` — the message handler then unconditionally calls `sendResponse({ success: true })` after awaiting `handleExport`. The popup is told the export succeeded whether or not a file was ever produced.
- `content-script.ts:82` — zero parsed pairs is treated as success: the popup shows "Ready" and lets the user click Export into a no-op.

There is no user-visible error surface anywhere in the extension. A user whose export silently fails has no signal at all — the most likely support complaint, and the hardest to diagnose remotely.
