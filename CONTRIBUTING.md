# Contributing

Thanks for taking an interest.

## Issues are welcome

Bug reports, ideas and questions are all useful. Please
[open an issue](https://github.com/nuncaeslupus/ai-chat-exporter/issues/new/choose) and pick the
template that fits.

- **Bug:** say what you did, what you expected and what happened, plus your
  version and operating system.
- **Idea:** describe the problem you have before the solution you picture.
- **Security problem:** do not open an issue — see [SECURITY.md](SECURITY.md).

## Pull requests are not accepted for now

This project is maintained by one person, who reviews and writes every change
themselves. Pull requests from outside will be closed without review — not
because they are unwelcome, but because reviewing outside code safely takes
more time than the project has.

If you have a fix, describe it in an issue. A snippet or a diff pasted into the
issue is fine, and if it is used you will be credited in the commit.

This may change as the project grows; this file will say so when it does.
