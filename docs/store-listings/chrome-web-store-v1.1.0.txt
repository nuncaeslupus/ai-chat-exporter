Extension Name

AI Chat Exporter and Printer

Short Description (132 characters max)

Export and print ChatGPT, Claude, and Gemini conversations to PDF, Markdown, Word and other formats with advanced formatting.

Detailed Description

Export your AI conversations with professional formatting - AI Chat Exporter makes it easy to save and share your conversations with ChatGPT, Claude, and Gemini in multiple formats.

✨ What's New in v1.1.0

Enhanced ChatGPT Support:

- Code Artifacts - Automatically extracts and formats code blocks from ChatGPT with proper syntax highlighting
- Web Search Citations - Preserves all web search results and citations with clickable links
- Improved Export Quality - Better image sizing and consistent formatting across all export formats

🎯 Key Features

Multiple Export Formats:

- PDF - Professional documents with proper pagination and formatting
- Markdown - Clean, readable text with full formatting support
- Word - Microsoft Word documents with proper structure
- HTML, JSON, Plain text and more

Smart Selection:

- Export entire conversations or select specific messages
- Interactive selection mode with visual feedback
- Batch export multiple conversations

Print Support:

- Direct printing with optimized layouts
- Page break control
- Print-friendly formatting

Rich Content Preservation:

- Code blocks with syntax highlighting
- Mathematical formulas and equations
- Images and visual content
- Tables and lists
- Web citations and references
- File attachments (Claude Projects)

Multi-Language Support:

- English, Spanish, French, German, Italian, Portuguese, Catalan
- Automatic language detection
- Localized user interface

🌐 Supported Platforms

- ChatGPT (chat.openai.com, chatgpt.com) - Including code artifacts and web search results
- Claude (claude.ai) - Including artifacts and project files
- Gemini (gemini.google.com) - Soon!

🔒 Privacy & Security

- 100% Local Processing - All data processing happens in your browser
- No Data Collection - We never see or store your conversations
- No External Servers - No data leaves your computer
- Open Source - Full transparency with public source code

📋 How to Use

1. Open any supported AI chat platform
2. Click the extension icon in your toolbar
3. Choose your export format
4. Select which messages to export (or export all)
5. Download your formatted conversation

🎨 Professional Output

All exports include:

- Conversation title and metadata
- Timestamps for each message
- Proper formatting and structure
- Code syntax highlighting
- Preserved images and attachments
- Web search results and citations

- Students - Keep learning materials and study notes
- Content Creators - Export content for blogs and articles
- Teams - Share conversations and knowledge
- Documentation - Create guides and tutorials
