Firefox Add-ons Listing - v1.1.0

Add-on Name
AI Chat Exporter and Printer

Summary (250 characters max)
Export and print ChatGPT, Claude, and Gemini conversations to PDF, Markdown, Word and other formats. Preserve code artifacts, web citations, images, and formatting. 100% private - all processing happens locally in your browser.

Description

Export your AI conversations with professional formatting and complete privacy. AI Chat Exporter makes it easy to save and share your conversations with ChatGPT, Claude, and Gemini in multiple formats.

✨ What's New in v1.1.0

Enhanced ChatGPT Support:
- Code Artifacts Extraction - Automatically extracts and formats all code blocks from ChatGPT responses with proper syntax highlighting in all export formats
- Web Search Citations - Preserves all web search results and citations with clickable links, domain names, and favicons
- Improved Export Quality - Better image sizing (200px max) and consistent formatting across PDF, HTML, and Markdown exports

🎯 Key Features

Multiple Export Formats:
- PDF - Professional documents with proper pagination, code highlighting, and page breaks
- Markdown - Clean, readable text with full formatting support and code blocks
- Word - Microsoft Word documents with proper structure and formatting
- HTML, JSON, Plain text and more

Smart Message Selection:
- Export entire conversations or select specific messages
- Interactive selection mode with visual feedback
- Preview before export
- Batch operations support

Print Support:
- Direct printing with optimized layouts
- Page break control for better readability
- Print-friendly formatting
- Browser print dialog integration

Rich Content Preservation:
- Code blocks with syntax highlighting (JavaScript, Python, TypeScript, etc.)
- Mathematical formulas and equations
- Images and visual content (properly sized thumbnails)
- Tables and lists with formatting
- Web citations with links and favicons
- File attachments from Claude Projects
- SVG artifacts with rendered previews

Multi-Language Interface:
- English, Spanish, French, German, Italian, Portuguese, Catalan
- Automatic language detection
- Localized user interface and messages

🌐 Supported Platforms

ChatGPT (chat.openai.com, chatgpt.com)
- Full conversation export
- Code artifacts extraction (React, JavaScript, CSS, SVG, etc.)
- Web search results and citations
- Image preservation

Claude (claude.ai)
- Conversation export
- Artifacts (code, documents, images)
- Claude Projects file attachments
- Extended context conversations

Gemini (gemini.google.com)
- Full conversation export
- Multi-turn dialogue support
- Image handling

🔒 Privacy & Security

- 100% Local Processing - All data processing happens in your browser, nothing is sent to external servers
- No Data Collection - We never see, store, or transmit your conversations
- No Tracking - No analytics, no telemetry, no cookies
- No External Servers - Everything runs locally on your device
- Open Source - Full transparency with publicly available source code
- No Account Required - Works immediately, no sign-up needed

📋 How to Use

1. Navigate to ChatGPT, Claude, or Gemini
2. Click the AI Chat Exporter icon in your toolbar (or use the in-page button)
3. Choose your preferred export format
4. Select which messages to export (or export all)
5. Click "Export" and your formatted conversation downloads immediately

🎨 Professional Output

All exports include:
- Conversation title and metadata
- Platform and model information
- Timestamps for each message
- Proper formatting and structure
- Code syntax highlighting
- Preserved images and attachments (thumbnails at 200px max)
- Web search results with citations
- Page numbers (PDF)
- Table of contents (when applicable)
