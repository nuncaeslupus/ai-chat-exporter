# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately through GitHub instead:
[Report a vulnerability](https://github.com/nuncaeslupus/ai-chat-exporter/security/advisories/new)
(the repository's **Security** tab → **Report a vulnerability**).

Include what you found, how to reproduce it, and what an attacker could do with
it. You will get an acknowledgement, and a fix or a decision, as soon as the
maintainer can look at it. This is a personal project maintained in spare time,
so there is no guaranteed response window.

## Supported versions

Only the latest release receives security fixes.
